## Selected projects

- **[DNS Cache Server](https://github.com/zemamba/dns-cache-server)** — Minimal macOS DNS proxy with a RAM-bounded LRU cache and stale-while-refresh behavior.
- **[HTTP Web Performance Server](https://github.com/zemamba/http_web_performance_server_go)** — High-throughput Go HTTP server for load testing.
- **[IPv4 Subnet Routes](https://github.com/zemamba/ipv4_subnet_rus)** — Route lists for Russian IPv4 ranges in formats for Keenetic, Linux, MikroTik, and OpenWrt.
- **[MiniDLNA Library Updater](https://github.com/zemamba/minidlna-update-media-library)** — Python utility for cover cleanup, thumbnail generation, and controlled library refresh.
- **[OpenClicker](https://github.com/zemamba/OpenClicker)** — Native macOS mouse, keyboard, and clipboard automation utility in Swift.
